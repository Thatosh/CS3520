STEP 6 — Explanation of `hello-world.s`

The `.data` section is used to declare and initialize data in memory, such as the string `"Hello world!"`. The `.asciz` directive stores the string followed by a null (`0`) byte, which marks the end of the string.

The `la` instruction loads the memory address of the `hello` string into register `a0`. This allows the system call to know where the string is stored in memory.

The `a7` register contains the environment-call number that tells the simulator which operation should be performed.

The `a7` register is loaded twice with different values because the program makes two different system calls. First, `a7 = 4` requests the string-printing operation, which prints the string whose address is stored in `a0`. Later, `a7 = 10` requests the program-exit operation.

Each `ecall` uses the value currently stored in `a7`, so the register must be changed between the two calls.
